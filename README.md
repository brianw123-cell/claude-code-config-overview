# How I run Claude Code

A one-page visual overview of the Claude Code setup I use every day to build client software.

**View it:** https://brianw123-cell.github.io/claude-code-config-overview/

It covers how the setup is organized: a short set of always-on instructions, preference files that load only when their trigger matches, permission tiers for what Claude can do on its own and what always needs my approval, hooks that check work before it ships, and the handoff routine between long sessions.

No client names, credentials or private files are included.
